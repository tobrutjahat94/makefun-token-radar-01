How the implied value is calculated

implied value = TVL × peer ratio (category) × growth × age

  • Peer ratio. For each category, take the live-token protocols in it — protocols whose token already trades — and take the median of their market-cap-per-TVL. That median is the only honest comp for a token that does not exist yet. Categories with few peers are shrunk toward the global median: (n × category median + 5 × global median) / (n + 5), then clamped to 0.01–3.00. A category with no live-token peer at all uses the global median.
  • Growth. 1 + 0.5 × 7-day TVL change, with the change clamped to ±30%. A protocol growing into its launch is worth more than one shrinking out of it.
  • Age. 0.90 + 0.10 × min(months listed, 48) / 48. A protocol that has run for years with real TVL and still no token is an overdue launch; the factor is small on purpose, so age only breaks near-ties and never outruns TVL.
  • What is ranked. Only protocols that record no token (no CoinGecko id and no ticker in the snapshot) and pass the watchlist's own cleanliness test: no version suffix, not a bridge, liquid-staking, restaking or CEX product, no wrapped or staked word in the name, not named after an exchange. A wrapped, staked or bridged product is a product of a token that already trades, not a fresh launch, so it gets no row.
  • What the numbers are. Implied values are this radar's claim, never a promise. The snapshot records no token; it does not prove a protocol has none. Values are rounded to whole dollars and nudged down by a dollar where rounding would tie two ranks, so the board stays strictly decreasing.
